# Personal Expense Tracker

A single-page application for tracking personal expenses, built as part of the Innovaxel Summer Internship 2026 assessment.

## Features
- Add, edit, and delete expenses (title, amount, category, date, notes)
- Data persists in browser localStorage
- Category-wise pie chart using Chart.js
- Summary cards: total spent, transaction count, top category
- Filter expenses by category and keyword search
- Input validation with inline error messages
- Fully responsive design (mobile + desktop)

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS v4
- Chart.js + react-chartjs-2

## Getting Started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
